Spring Boot 3 + MyBatis-Plus + MySQL 8 + Vue 3 + Element Plus · 关系与流程为项目实现示意

一、系统架构

前端层
Vue 3
登录/布局Vue Router 守卫 · Pinia 登录态 · JWT 存储
10 个业务页面仪表盘/房型/房间/床位/旅客/入住/退房/账单/报表
Element Plus + ECharts表格/表单/弹窗 · 饼图/折线/柱状

Spring Boot
Controller9 个 REST 接口模块 · @Valid 参数校验

全局统一响应 · 全局异常 · JWT 拦截 · 乐观锁
▼ JDBC（MyBatis-Plus）▼

MySQL 8

机制InnoDB · utf8mb4 · 外键 · 唯一索引防并发重复入住

二、核心业务流程

旅客登记
姓名/身份证/性别/住址/电话
→
办理入住
自动推荐床位 · 空房任意性别 · 同性别续住 · 禁止混住
→
在住
床位/房间置占用 · 房间记性别
→
办理退房
天数=MAX(DATEDIFF,1) · 金额=天数×单价快照
→
生成账单
释放床位 · 房间无人则恢复空房
→
支付结算
UNPAID → PAID · 记录支付流水

三、数据表关系（ER 示意）

表关键字段关系
sys_userid, username(UK), password, role独立（登录认证）
room_typeid, orientation, type_name, bed_count, daily_price1 ── N → room（room_type_id）
roomid, room_no(UK), room_type_id, orientation, status, current_gender, version1 ── N → bed（room_id）；1 ── N → check_in_record
bedid, room_id, bed_no, status ｜ UK(room_id, bed_no)1 ── N → check_in_record（bed_id）
guestid, name, id_card(UK), gender, phone, address1 ── N → check_in_record；1 ── N → bill
check_in_recordid, guest_id, room_id, bed_id, check_in_date/out_date, status, daily_price_snapshot, days, total_amount, active_bed_id(UK), active_guest_id(UK)1 ── N → bill（check_in_record_id）
billid, bill_no(UK), check_in_record_id, guest_id, room_no, bed_no, days, daily_price, total_amount, pay_status退房时生成
operation_log / payment_recorduser_id, module, action / bill_id, pay_method, amount附属表（可选）

UK = 唯一索引；active_bed_id / active_guest_id 在“在住”期间非空，退房后置 NULL，配合唯一索引防止同一床位/旅客被重复入住。

四、并发控制要点

事务入住/退房全程 @Transactional，异常回滚
行锁SELECT … FOR UPDATE 锁定床位/房间/记录
唯一索引兜底uk_active_bed_id · uk_active_guest_id
乐观锁room.version 防房间状态覆盖
友好提示DuplicateKeyException → “床位/旅客被并发占用”
